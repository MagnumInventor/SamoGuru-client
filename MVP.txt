СамоГуру — це веб-додаток для управління персоналом, графіками роботи, навчанням, комунікацією та аналітикою в ресторанному бізнесі. Розроблений для оптимізації операційних процесів, підвищення ефективності роботи команди та забезпечення прозорості управління.

Поточний MVP: Основні функції
1. Управління графіками роботи
Створення, редагування, публікація та архівування розкладів для працівників.
Персональний перегляд розкладу (calendar view) для кожного працівника.
Друк та експорт розкладів у PDF/CSV (заплановано).
Автоматичні рекомендації щодо покриття змін на основі пікових годин (заплановано).
2. Навчання та стандарти
Навчальні модулі та тести для стажерів та працівників.
Чек-листи для виконання завдань.
Довідники та правила (сервірування, меню, розподіл посуду).
3. Аутентифікація та контроль доступу
Реєстрація через коди працівника/менеджера.
JWT у cookie для захищеного доступу до системи.
Рольова модель: admin, helper, waiter, trainee.

4. Комунікація та мотивація
Система мотивації (штрафи, бонуси, гейміфікація — заплановано).
Push-повідомлення про зміни графіку, термінові новини (заплановано).
Живий чат для внутрішньої комунікації (заплановано).
5. Аналітика та звітність
Статистика графіків: кількість змін, відвідуваність, ефективність.
Історія та звіти зарплат за минулі місяці (заплановано).
Динаміка прибутку та синхронізація з API Syrve для порівняння графіку з фактичною відвідуваністю (заплановано).
Заплановані функції
3.9.xS (Advanced employee management)
Додавання нових посад (менеджер, шеф-кухар тощо).
Сторінка “Штат”: список працівників, їх ставки, історія змін.
Синхронізація з API Syrve для підрахунку зарплат на основі графіку та відвідуваності.
Нарахування бонусів/премій до зарплати.
3.10.xS (Salary & Statistics)
Розрахунок зарплати працівників на основі графіку та KPI.
Історія зарплат за минулі місяці.
Динаміка прибутку: календарний графік доходів.
4.2.x+ (Chat microservice)
Живий чат між працівниками.
Розсилка повідомлень для окремих посад/працівників.
Планування оголошень з можливістю позначити “Терміново”.
4.1.x+ (Multi-restaurant architecture)
Масштабування до рівня мережі ресторанів.
Інтерфейс супер-адміна для управління всіма точками.
Майбутні можливості
Тренінги та довідники: оновлювані модулі для навчання персоналу.
Система штрафів і бонусів: контроль дисципліни та стимулювання якості.
Аналітика та прогнозування: розширені звіти та автоматичні рекомендації.
Інтеграції: підключення CRM, систем обліку товарів, зарплат.
Очікувані результати
Оптимізація процесів: зниження часу на складання графіків, автоматизація розрахунків зарплат.
Підвищення ефективності: краще покриття змін, швидше навчання персоналу.
Прозорість управління: доступ до статистики, історії змін, звітів.
Покращення комунікації: внутрішній чат, push-повідомлення.
СамоГуру — це модельний додаток, який забезпечує ефективне управління ресторанним бізнесом, знижує витрати часу та підвищує якість роботи команди.
